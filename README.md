# StanApp

A mobile-first personal property management app for owners who manage multiple properties — apartments, houses, and garages. Track usage, tenants, expenses, rent payments, team access, and financial reports in one place.

**Platforms:** iOS and Android (React Native + Expo)  
**Languages:** English and Croatian (Hrvatski)  
**Design:** Naslov — Inter + Fraunces, semantic colour tokens

---

## Quick start

```bash
pnpm install
cp .env.example .env   # add Supabase (+ optional Google) keys
# apply DB via migrations only: npx supabase db push  (or db reset locally)
pnpm start
```

See [docs/getting-started.md](docs/getting-started.md) for the full database setup.
